# DUST II — STRIKE PROTOCOL

一个从零实现的浏览器 3D 第一人称战术射击原型：**React 18 + TypeScript + three.js + Vite**。  
地图、角色、武器、UI 全部由代码生成，声音由 Web Audio API 实时合成，不使用任何外部模型、贴图或音频文件。

## 运行

```bash
npm install
npm run dev
```

打开终端提示的地址（默认 `http://localhost:5173`），选择 CT / T 后点击“部署至 DUST II”。

生产构建：

```bash
npm run build
npm run preview
```

## 操作

| 输入 | 功能 |
| --- | --- |
| `W A S D` | 移动 |
| `Shift` | 静步 |
| `Space` | 跳跃；阵亡观战时立即接管队友 |
| 鼠标左键 | 开火 / 挥刀 |
| 鼠标右键 | AWP 开镜（按住） |
| `R` | 换弹 |
| `1` / `2` / `3` | 主武器 / 副武器 / 战术刀 |
| 鼠标滚轮 | 循环切换武器 |
| `E` | 按住安放 / 拆除 C4 |
| `B` | 冻结时间打开军械库（第 2 回合起） |
| `Tab` | 战术计分板 |
| `Esc` | 释放鼠标并暂停 |

第一回合为手枪局：双方仅有 Glock / USP 与战术刀，无主武器、无护甲。第 2 回合起按 `B` 选择步枪、AWP、沙鹰与护甲。

## 已实现系统

- **Dust2 核心区域**：T 出生点、CT 出生点、A 大、A 点、中门与可穿越双门、猫道、B 洞、B 点。所有区域通过实机碰撞与 A* 寻路验证互通。
- **5v5**：1 名玩家 + 4 名 AI 队友，对抗 5 名 AI 敌人；阵亡后自动 / 按空格接管存活队友。
- **角色**：程序化类人模型，独立头部、躯干、双臂、双腿、持枪姿态、行走动画与死亡倒地；CT / T 使用不同配色、头盔/面罩和臂章。
- **武器**：AK-47、M4A4、AWP、Glock-18、USP-S、沙漠之鹰、战术刀。具有射速、弹匣、备弹、换弹、扩散、后坐力、AWP 开镜、第一人称手持模型、枪口火焰与曳光弹。
- **命中判定**：头、胸、腹、手臂、腿五个独立 hitbox。爆头倍率 2.0；护甲按武器穿透率吸收伤害。
- **C4**：回合开始分配、持包者死亡掉落、队友拾取、A/B 点安放、40 秒倒计时、CT 拆除、爆炸与回合结算。
- **AI**：网格 A* 寻路、路径平滑、视野/墙体遮挡检测、自动交战、换弹、推进包点、安放、回防、拆包、卡墙恢复。
- **回合**：冻结时间、手枪局、军械库、比分、比赛结束。
- **HUD**：动态准星、生命/护甲、武器与弹药、Killfeed、目标提示、行动进度、计分板、AWP 2D 瞄准镜、小地图。
- **小地图**：实时绘制 Dust2 俯视轮廓与 A/B 点，显示自己、队友、当前被队伍视野发现的敌人，以及 C4。
- **音频**：Web Audio 程序化合成武器开火、换弹、脚步、开镜、命中、击杀、安放、拆除、倒计时与爆炸声。

## 架构

```
src/
  game/
    Game.ts        游戏循环、全局状态、回合/炸弹流程、玩家控制、AI 状态机、相机、HUD 快照
    map.ts         程序化 Dust2 blockout、材质、道具、碰撞体、门与小地图数据
    navigation.ts  网格化 A*、八方向移动、拐角防切、路径平滑
    character.ts   类人角色、hitbox、持枪姿态、第一/第三人称武器几何体
    weapons.ts     可扩展武器数据与配装
    audio.ts       Web Audio 合成器
    math.ts        碰撞、射线、角度与几何工具
    types.ts       共享数据类型
  ui/
    HUD.tsx        2D HUD
    Minimap.tsx    Canvas 实时小地图
    MainMenu.tsx   主菜单/阵营选择
    BuyMenu.tsx    军械库
  App.tsx          React 生命周期与游戏实例桥接
```

渲染循环使用 `requestAnimationFrame`；固定上限的帧间步进驱动实体、AI、弹道、C4 与回合状态。游戏引擎以约 18 Hz 向 React 推送轻量 HUD 快照，小地图通过独立 Canvas 循环以约 30 Hz 读取实时世界状态，避免每帧触发 React 树更新。

所有运行时第三方依赖仅为 `three`、`react`、`react-dom`；Vite / TypeScript 为开发构建工具。
