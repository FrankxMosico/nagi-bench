# 水运仪象台 · 一滴水如何报时

约 30 秒的可交互 3D 科普短片，直接打开 `dist/index.html` 即可离线观看。点击左下角按钮暂停或播放，拖动时间轴回看；浏览器若阻止自动播放声音，可点右下角「声音」。

## 开发

```sh
bun run dev
bun run build
```

Vite 将 Three.js 与全部场景代码打入本地资源；构建脚本将单个 JS 包的入口改为普通延迟脚本，使 Chromium 能从 `file://` 加载。项目不请求网络，也不使用外部模型、贴图或音频文件。

## 物理模型

`src/physics.js` 以每秒 120 步积分。各水斗的水量产生重力矩；盛水杯的重量使擒纵杆偏转；止挡碰撞让水轮一次前进一个齿距。齿轮用无滑动角速度冲量约束连接水轮、小齿轮、竖轴、天球、浑仪和凸轮。凸轮与弹簧滑杆接触，滑杆推动偶人；木槌由自身转动惯量与弹簧力演算并与铜钟发生碰撞。拖动时间轴时重置并重新计算全部物理步，画面中的机械姿态只读取物理状态。此模型是面向讲解的结构示意。

配乐、流水、齿声与钟声均由 Web Audio API 在运行时合成。
