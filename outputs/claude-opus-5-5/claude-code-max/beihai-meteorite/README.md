# 《尘世之外》

一部约 6 分钟（356 秒）的程序化体素短片，改编自刘慈欣《三体Ⅱ·黑暗森林》中章北海购买铁陨石、制作陨石子弹、在同步轨道上射杀三位航天元老并伪装成"陨石雨"的段落。

画面、人物、场景、光影、字幕与全部声音均由代码在浏览器中实时生成：Three.js + AgentBench Cinematic Player + Voxel Kit，Web Audio API 合成全部音效与配乐，不含任何外部资源。

```bash
bun run build      # 产出 dist/index.html + dist/assets/
bun run preview    # 本地预览构建结果
```

> 依赖由平台离线预装（`node_modules` 指向只读工具链），不需要也不应运行 `bun install`。
> Vite 配置以 `--configLoader native` 加载（只读的 node_modules 无法写入临时打包文件）。

## 改编取舍

原文的核心是一个"陨石"的反讽：收藏者说陨石"来自尘世之外"，章北海以"对要送的人的尊重"付全价；这些陨石被车床切成三十六段，装进无壳子弹，最后在真空里飞回天上，被受害者自己喊成"陨石雨"。影片围绕这条线组织，其余全部为它服务：

| 段落 | 时间 | 处理 |
| --- | --- | --- |
| 序：天外 | 0:00–0:15 | 一块铁陨石在星空中翻滚，落入地球夜面化作火线；片名。为结尾"陨石雨"埋下镜像。 |
| 胡同·收藏者 | 0:15–1:46 | 保留"您是军人吧""地球也是一块大陨石""你已经开始砍价了""铁陨石的要求""付全价——对要送的人的尊重"。删去火星陨石、黑格出价、南极考察细节等。内心独白点出"小世界"与"为生存而战"的主题。 |
| 车间·夜 | 1:46–2:12 | 常伟思的电话（"不能出海的舰队政委"）交代他即将上太空；数控车床的无对白蒙太奇，计数器到 036，带走刀具与碎屑。 |
| 地下室 | 2:12–2:48 | 拔弹头、粘陨石段、装弹；四声封闭空间里的枪响（强反射混响 + 耳鸣主观声）；弹孔很小、在牛肉里碎成砂砾——"看不出加工的痕迹"。 |
| 一号基地·气闸 | 2:48–3:02 | 摘下定位单元留在床铺上（预谋），父亲的遗照；气闸泄压，声音随空气一起消失。 |
| 同步轨道 | 3:02–5:35 | 黄河站全景、独处的独白与父亲；日落三阶段（接触地平线→半沉的"戒指"→三分之二）；出口灯由红转绿、三十人出舱排队；面罩转透明露出面孔；摘手套、取枪、装镜、三十次无声击发（远景如萤火）；子弹飞行的十秒被慢放并与"无辜？"独白交叉剪辑；撞击时全片唯一的绝对静默；口型"陨石雨！"；警报中拖回伤者；关掉无线电，飞向一号基地。 |
| 尾声 | 5:35–5:56 | 第二天清晨，收音机播报"微陨石撞击事故"，收藏者叹一声"天外来的东西啊……"，镜头移过柜中三个空着的丝绒凹坑。 |

原文中两处不一致（五个弹洞/四发子弹，五公里/十公里）在片中统一为四个弹孔、五公里（500 m/s × 10 s）。

## 视听设计要点

- **体素语言**：所有人物用 Voxel Kit `createFigure` 装配，五官/表情/徽标全部画在 64×64 贴图上；服装为独立衣服贴图层（航天服、大衣、毛衣、开衫）。头盔、背包、手枪、瞄准镜、弹夹、手套等道具挂在 kit 的锚点上，用 `voxelModel` / `buildVoxelGeometry` 构建；地球、太阳、空间站、船坞骨架、胡同、房间全部为体素几何。
- **色彩脚本**：胡同的金色午后 → 收藏室的钨丝灯与玻璃柜光 → 车间的冷白光池与月光窗 → 地下室的单灯与硝烟 → 太空的黑、蓝、日落橘红 → 尾声的晨光。
- **画幅**：2.39:1，自定义调色 pass（暗角、颗粒、闪白、渐隐、瞄准镜遮罩与分划、耳鸣模糊）+ Bloom + ACES。
- **声音的物理规则**：地下室枪声用计算出的混凝土小房间冲激响应（密集早期反射 + 明亮尾音），并让主限幅器真正工作；真空里外部声音一律不传播——击发只有经手臂传导的闷响，推进器是经服装传导的低频，撞击时刻全部静音，"陨石雨！"只以口型 + 字幕呈现，警报只经无线电听到。

## 配音清单（字幕来源）

`src/voice.ts` 导出唯一的 `voiceCues: VoiceCue[]`，49 条，每条固定七个字段 `id / kind / speaker / text / delivery / start / end`。播放器字幕（画面底部居中 `【说话者】文本`）直接由它驱动；角色口型开合、无线电/电话/广播的底噪与静噪声也由同一清单生成，改动时间轴时画面、字幕、声音一起移动。`kind` 取值：`dialogue`、`monologue`（内心独白）、`phone`、`chatter`、`radio`、`mouthed`（真空中无声的口型）、`broadcast`。

## 代码结构

```
src/
  main.ts            入口：渲染器、后期、播放器、舞台、控件、音频总线、海报帧
  timeline.ts        全片时间轴常量（镜头、动作、音效共用）
  voice.ts           配音/字幕清单
  post.ts            Bloom + 调色/瞄准镜/渐隐 pass
  overlay.ts         片名、地点字幕、头盔 HUD、测距读数、片尾
  audio/
    kit.ts           合成工具：噪声缓冲、可跳转的包络、计算冲激响应、调制
    sounds.ts        所有音效、环境声与配乐的合成工厂
    cues.ts          音效 cue 表与电平校准表
    mix.ts           分组总线电平
  world/
    cast.ts          角色：贴图绘制、表情、服装、航天头盔/面罩/背包
    props.ts         手持道具（体素）
    sky.ts           星空、体素地球（昼夜着色、城市灯光、大气）与太阳
    sets/*.ts        各场景（胡同、收藏室、车间、地下室、一号基地、空间站、序幕）
    shots/*.ts       全部镜头：每个镜头由绝对时间推导整帧状态，跳转确定
tools/               开发用检查工具（不进入构建产物）
```

## 验证

构建环境中没有可用的浏览器（`/usr/bin/chromium-browser` 只是未安装的 snap 占位脚本，沙箱也禁止 X11/Unix socket），因此用以下工具代替人工观看：

- `bun tools/harness/run.ts`：在模拟 DOM + WebGL2 桩 + 严格的 Web Audio 桩中运行 **构建后的 `dist/`**：点击海报播放、推进帧、暂停、拖动进度条、调音量、恢复、整片播放到结束再重播；检查每个镜头都被渲染、49 条字幕全部出现且格式正确、每个音效 cue 都触发且 Web Audio 用法合法、uniform 上传无异常、控制台无错误，并报告播放过程中才编译的着色器程序（会在真实 GPU 上造成卡顿；目前为零，全部在加载时预热）。
- `bun tools/preview.ts --t 250,301 --sheet name [--pp]`：用 CPU 光栅化器渲染真实场景图的近似画面（无阴影/Bloom），用于检查构图、调度、光线与连续性；`--pp` 改为逐像素光照（与 WebGL 一致，近景人脸更准确）。
- `bun tools/audio-render/run.ts`：离线实现 Web Audio 节点图，经真实的播放器与 cue 总线渲染全片声音（16 kHz），输出每个 cue 的峰值/RMS 与逐秒响度，用于校准混音。
