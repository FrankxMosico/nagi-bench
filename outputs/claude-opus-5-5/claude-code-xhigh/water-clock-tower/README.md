# 水运仪象台 · 水如何驱动一座天文钟

一部约 34 秒、可在浏览器中直接打开的 3D 科普短片：讲清北宋苏颂水运仪象台（1088 年）
如何靠水驱动、一格一格走、按时报时。

```
bun run build      # 类型检查 + 构建到 dist/
bun run dev        # 开发服务器
```

`dist/index.html` 不依赖任何网络资源：脚本打包为经典（非 module）脚本，既可通过 http 访问，
也可直接双击以 `file://` 打开。

## 影片结构

| 时间 | 内容 |
| --- | --- |
| 0–5 s | 片头：黄昏中的仪象台 |
| 5–9.6 s | ① 平水壶恒定水位 → 出水口 → 水斗 |
| 9.6–18.4 s | ②–⑤ 擒纵（慢放 + 天关放大镜）：水斗装满 → 枢衡压下 → 天条 → 天衡 → 天关抬起 → 枢轮转一格 → 天关落下锁住 |
| 18.4–21.6 s | ⑥ 冠齿轮 → 灯笼齿轮 → 天柱 |
| 21.6–24 s | ⑦ 天柱 → 浑象、浑仪 |
| 24–29.4 s | ⑧ 天柱 → 机轮 → 拨牙拨动木人敲钟、击鼓，时辰牌转到窗口 |
| 29.4–34.4 s | 总结与升水轮（水循环） |

顶部的因果链提示条会随**物理状态**逐级点亮（例如枢衡真的压下时才点亮“枢衡”）。

## 物理（Rapier 3D，实时计算）

仪象台的所有机械运动都由 `src/physics/machine.ts` 中的 Rapier 刚体仿真实时计算，渲染层只读取刚体位姿：

- **水**：出水口以恒定流量放出水滴（球形刚体），落进水斗，重量真实地压在水斗上。
- **擒纵**：16 只水斗用铰链挂在枢轮上；注水位的水斗搁在枢衡（带枢权的杠杆）格叉上；
  枢衡与天衡之间是只能拉不能推的绳索约束（天条）；天衡一端的天关靠接触挡住轮辐外端的横档。
  水斗够重 → 枢衡下压 → 天条拉动天衡 → 天关抬起 → 枢轮在满水斗的重力下转动 → 天关落下卡住下一根横档。
- **传动**：冠齿轮—灯笼齿轮、正齿轮全部靠轮齿碰撞啮合；浑象、浑仪经双十字万向节带动绕倾斜极轴转动。
- **报时**：机轮上的拨牙推动木人的脚，木人被扭簧与重力拉回时槌头撞上鼓或钟（碰撞事件触发音效）。
- **升水轮**：由关节马达驱动，代表人力摇转。

物理以 240 Hz 固定步长推进，结果确定。`src/film/physEvents.json` 由 `bun tools/events.ts 38 --write`
离线运行同一套仿真生成，只用于把慢放区间和字幕切换对齐到实际的机械动作上；
镜头与字幕按影片时间编排，不影响任何零件的运动。

## 声音

配乐（五声音阶的拨弦、笛声、持续音垫）与音效（水流、天关撞击、木轮隆隆、鼓、钟）全部用
Web Audio API 在运行时合成；音效由物理碰撞事件触发，按镜头距离与屏幕位置调整音量和声像。
主输出经压缩器与限幅器，离线渲染测得峰值约 −3 dBFS。

浏览器拦截自动播放时会显示“播放”按钮；若一直无人点击，8 秒后静音开播，并提供“开启声音”按钮。

## 画质

检测到软件渲染（如无头浏览器的 SwiftShader）时自动降级：半分辨率、关闭阴影与抗锯齿、Phong 材质，
并逐帧与 GPU 同步，保证影片时钟与真实时间一致、截图不超时。URL 参数 `?high` / `?low` 可强制画质。

## 调试参数与工具

- `?t=12&freeze`：跳到影片第 12 秒并冻结（物理会从头快进到该时刻）
- `?perf`：在控制台输出帧耗时与物理事件
- `tools/`：无头仿真（`sim.ts`、`events.ts`）、截图（`film.ts`、`shot.ts`）、同步检查（`sync.ts`）、
  音频电平（`audiotest.ts`）、`file://` 打开测试（`filetest.ts`）等
