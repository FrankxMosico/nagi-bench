# 尘世之外 · 方块电影

改编自刘慈欣《三体Ⅱ·黑暗森林》中章北海购买陨石、制作陨石子弹、在同步轨道刺杀三名航天界人物的段落。
Three.js 程序化 3D 短片，总长 **5 分 52 秒（352 秒）**，片头片尾都算在内。

## 运行

```bash
bun run build          # 产出 dist/index.html 与 dist/assets/
bun run preview        # 本地静态服务预览（或用任意静态服务器打开 dist/）
```

点击海报「开始放映」后播放（同时解锁 Web Audio）。空格键播放/暂停，← → 快退/快进 5 秒；
底部控制条有时间轴、音量和全屏。画面为 2.35:1 宽银幕遮幅。

## 声音

- **全部语音只以字幕呈现**，不合成任何人声。完整语音清单在 `src/voice.ts`：单一导出的 `voiceCues: VoiceCue[]`，
  每条固定 `id / kind / speaker / text / delivery / start / end` 七个字段，字幕直接由它驱动，可按 `id` 逐条配音接入。
  `kind` 包括 `dialogue`、`monologue`、`broadcast`、`radio`、`system`（航天服提示）、`lipread`（只见口型，真空中听不到）。
- **所有音效、环境声、音乐都在运行时用 Web Audio API 合成**（`src/audio/`），不含任何音频文件、录音或 `data:audio`。
  噪声缓冲和房间脉冲响应都由代码生成。
- 遵守声学环境：地下室枪声是瞬态爆裂、胸腔低频、密集明亮的早期反射和短而硬的尾音，随后耳鸣；
  真空中外部枪声完全静默，只有航天服内传导的闷震、机械声、呼吸、心跳与无线电；无线电带限并削波；头盔内声音近、干、偏低频。
- 声音事件与画面共用 `src/story.ts` 里的时钟（射击时刻、十秒拉伸映射、落料节拍等），跳转后也保持同步。

## 视觉

- 所有人物由 `@agentbench/voxel-kit` 的 `createFigure` 装配，骨架与比例不改；五官、表情、眼镜、航天服面板、面罩
  （不透明 → 像素溶解 → 透明 → 碎裂带血）全部画在 64×64 贴图上，身体与服装分层。
- 场景、道具、地球、云层、大气、太阳全部是体素几何（`buildVoxelGeometry` / `voxelSphere`），地球与大气为自定义着色器。
- 黄河站为 1 公里的体素轮辐，舱门区域另有高精度面板；星空背景与地球、太阳在独立渲染通道中，与 5 公里的视差无关。
- 后期：UnrealBloom、ACES 色调映射、分场景冷暖调色、暗角与细颗粒。

## 目录

```
src/main.ts            播放器、渲染器、控制条、海报
src/world.ts           场景与相机、每帧画面状态（淡入淡出、瞄准镜、头盔 HUD、字卡）
src/shots.ts           全部分镜（镜头 = 绝对时间区间内的纯函数）
src/voice.ts           语音/字幕清单
src/story.ts           太空段落的故事时钟、日落进度、射击时刻
src/sets/*.ts          胡同、收藏者的屋子、车间、地下室、黄河站、合影人群、天空
src/cast/*.ts          贴图绘制、演员封装、方块手臂指向
src/audio/*.ts         合成工具、音效工厂、声音时间轴
tools/                 开发用：离线软件光栅预览、Web Audio 严格 mock 测试、字幕清单校验、性能测量（不参与构建）
```

## 开发检查

```bash
bun run typecheck
bun tools/preview.ts sweep 0.1          # 逐 0.1 秒跳转全片，检查异常 / NaN 相机 / 镜头空档
bun tools/preview.ts 12 120 300         # 用软件光栅器渲染指定时刻到 tools/out/
bun tools/audio-test.ts                 # 严格 mock AudioContext：全片实时回放 + 多次跳转，检查调度错误
bun tools/voice-check.ts                # 语音清单字段、重叠与字幕阅读速度
```
