# 水运仪象台 · 一滴水如何报时

一部约 31 秒、可在浏览器里直接打开的 3D 科普短片。它讲清北宋苏颂水运仪象台（1088）的工作链条：

**恒定水流 → 受水壶称重 → 枢衡压下 → 天条 → 天衡翘起、天关抬开 → 枢轮走一格（擒纵）→ 地轂齿轮 → 天柱 → 浑象 · 浑仪 · 木阁报时**

## 运行

```bash
bun install      # 依赖已预装时可跳过
bun run build    # 类型检查 + Vite 构建，输出 dist/
bun run dev      # 开发服务器
```

`dist/index.html` 可以直接双击用 `file://` 打开（离线，无任何网络请求）：构建产物是一个经典
`<script defer>` 脚本（IIFE），Rapier 的 WASM 已内嵌在脚本中。浏览器若禁止自动播放声音，会显示
“▶ 播放（有声）”按钮；允许自动播放时直接开始。片尾有“重播”。

## 物理：所有机械运动都由 Rapier 实时计算

`src/sim/sim.ts` 用 Rapier（`@dimforge/rapier3d-compat`，240 Hz）搭建整台机器，没有任何关键帧或直接设置位置：

| 部件 | 物理实现 |
| --- | --- |
| 水 | 从平水壶壶嘴以恒定速率射出的刚体水滴（密度 1000 kg/m³），落进受水壶、溢出后流入退水壶 |
| 受水壶 ×12 | 用铰链挂在枢轮上的刚体，可在限位内相对轮子转动——这样才能被“称” |
| 格叉 / 枢衡 / 枢权 | 带配重的杠杆（秤）。壶里水的力矩超过配重时，格叉向下并向外摆开，壶从叉尖滑落 |
| 天条 | Rapier rope joint（只受拉的链条），连接枢衡与天衡，留有少量松弛以吸收冲击 |
| 天衡 / 天关 | 上方杠杆。天关是一根圆柱，落座时比天衡支点低 3 cm，轮齿的水平推力只会把它压得更稳；只有天条把它提起后，轮子才能通过 |
| 枢轮 | 由满水受水壶的重力驱动；天关抬起时转动，落回后卡住下一齿——每次正好 30° |
| 地轂 → 天柱 | 轮轴端的冠状销齿轮与天柱上的灯笼齿轮靠接触啮合（节圆半径相等，1:1） |
| 浑象、浑仪 | 极轴按开封纬度（35°）倾斜，由天柱上的灯笼齿轮经倾斜的销齿圈接触驱动，转向与天球周日运动一致 |
| 木阁 | 天柱上的机轮带着 12 个举时辰牌的木人；拨钉拨动击鼓、敲钟木人的手臂（铰接杠杆），木槌靠重力落下敲击 |

镜头与字幕不受物理约束。导演模块（`src/film/director.ts`）只决定看哪里，以及模拟时间流逝的快慢：
擒纵特写前略微调节时间流速，让一次“称满→放行”正好落在特写里；随后慢放（×0.25 / ×0.75），
镜头沿“格叉 → 天条 → 天衡 → 天关 → 枢轮”这条因果链移动。
字幕和标签由物理状态驱动（例如受水壶上实时显示的水重，以及顶部因果链里正在运动的环节）。

`tools/simtest.ts` 是不渲染画面的物理调试工具：`bun tools/simtest.ts 60` 会打印每次称满、放行、锁住的时刻和每步转角。

## 声音：全部由 Web Audio API 实时合成

`src/audio/audio.ts` 不使用任何音频文件：
- 配乐：五声音阶，类古琴的拨弦（Karplus–Strong 预先渲染到 AudioBuffer）、柔和的持续音垫和低音、带气声的笛音、锣；
- 音效由物理事件触发：水滴、水流声、天关卡齿的“咔哒”、枢衡摆动的吱呀、齿轮的嗒嗒声、木人击鼓与敲钟；
- 总线依次经过压缩器和限幅器。离线渲染整条声轨测得峰值约 −2.4 dBFS、平均约 −22 dBFS，没有削波。

## 美术

所有几何体和贴图都在运行时用代码生成（canvas 贴图：木纹、筒瓦、石材、带二十八宿的星图、时辰牌、远山），
没有外部模型或图片。

## 自检工具（开发用）

- `bun tools/capture.mjs 1,5,10 outDir [WxH]`：在无头 Chromium 中按影片时间逐帧确定性截图（`?capture` 模式）；
- `bun tools/audiotest.mjs`：用 OfflineAudioContext 渲染整条声轨并报告响度（`?audiotest` 模式）；
- `bun tools/robust.mjs "6,7;5.3,7"`：在不同起始相位下检查擒纵段的时间安排；
- `?free`：自由轨道相机查看机器运转。
