# 把流水变成时间

一部约 32 秒、直接在浏览器播放的 3D 科普短片，解释北宋苏颂主持营造的水运仪象台如何把水力变成机械步进，再驱动天文仪器和木人报时。

## 打开与构建

- 直接用浏览器打开 `dist/index.html`。所有脚本、样式都在本地，不需要服务器或网络。
- 点击右上角声音按钮启用配乐、水声、止挡声和钟声。默认静音自动播放，以兼容浏览器的音频自动播放限制。
- 底部支持暂停、重播、跳转章节和全屏。快捷键：空格播放/暂停，M 开关声音，R 重播。
- 开发：`bun run dev`。
- 构建：`bun run build`。

运行时依赖仅为 Three.js 0.180.0 与 cannon-es 0.20.0。Vite 8.2.0 负责构建。构建使用 native 配置加载器，并输出普通延迟执行脚本，支持 `file://` 离线打开，避开本地 ES module 的跨域限制。

## 影片段落

| 时间 | 画面与原理 |
| --- | --- |
| 0–3.8 秒 | 全台总览：水力、天文与报时 |
| 3.8–9 秒 | 溢流水箱稳定水位，向水轮均匀供水 |
| 9–14.8 秒 | 受水斗增重，重力产生转矩 |
| 14.8–20.5 秒 | 秤杆触发止挡释放，水轮走一格后重新锁住 |
| 20.5–26 秒 | 齿轮和竖轴把步进送到浑仪、浑象 |
| 26–32 秒 | 报时轮推动木人手臂，敲钟；最后回到全台 |

## 实时物理实现

机械没有关键帧、按时间插值的角度或逐帧指定刚体位置。画面中的机械变换只从 Cannon 刚体的位置与四元数读取。镜头与文字使用时间线。

- 世界以 1/120 秒固定步长求解。水以有质量的粒子刚体表示，受重力和碰撞作用。
- 粒子进入水斗区域后通过锁定约束近似斗内暂存的水，质量和重力通过约束加载到水轮，随轮到下方后解除约束、落入承水盘。没有为水轮添加驱动电机或恒定驱动转矩。
- 秤杆是带回位弹性的铰接刚体。受水位置的载荷转矩通过简化的杠杆力传递模型压动秤杆，实际角度越过阈值时解开止挡。止挡使用零速约束；转过下一个固定齿位后重新启用，不强设角度或角速度。
- 五组齿轮关系用 Cannon 约束方程求解角速度比例和反向力矩，传动负载会反作用于水轮。
- 报时凸轮与木人手臂通过真实刚体碰撞接触。手臂带回位弹性，槌头与钟壁碰撞、且重新抬起后，才合成一次钟声。
- 章节跳转会从初始状态重新步进物理世界到指定时刻，而不是摆放一张预设机械姿态。水粒子的初始分布用固定随机种子保证可复验。

这是一部原理短片，不是《新仪象法要》的尺寸复原。水箱、斗数、止挡连杆、报时层与齿轮比均经简化，时间比例已压缩；报时层用一组凸轮、木人和钟代表原台的多层钟鼓与出牌机构。影片内有简化标注。

## 生成资产与音频

模型全部由代码中的几何体、车削体和圆环组成；星点、刻度也是程序生成。没有模型、贴图、字体或音频资产下载。

音频全部由 Web Audio API 在运行时生成：过滤的噪声形成水声，正弦与三角波形成配乐与机械声，非整数倍的衰减泛音形成钟声。声音包络有渐入渐出，经总音量和动态压缩器输出。

## 自检

`checks/` 保存本地 Chromium 的检查脚本和截图，`preview-final/` 保存真实播放时的 0、5、10、20、30 秒预览。检查产物不进入 `dist/`。

- `bun checks/watch.mjs`：通过 `file://` 打开构建，重新计算各时间点并截图。
- `bun checks/physics.mjs`：检查各段的水斗质量、步进、传动约束与钟击计数。
- `window.__film.state`：只读物理与渲染诊断；`seek(t)` 通过重新模拟定位。

已完成的检查：本地文件方式只请求 HTML、JS、CSS 三个本地文件，控制台无错误；暂停同时冻结影片和物理，恢复、章节跳转、重播均通过。音频运行于 44.1 kHz，抽样输出峰值约 0.068（满幅为 1），未见削波。32 秒物理复算得到 31 次完成步进、22 次有效钟壁碰撞。
