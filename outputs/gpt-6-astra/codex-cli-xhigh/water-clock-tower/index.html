关于这次复原

一座由水驱动的
天文钟楼。

北宋苏颂主持建造的水运仪象台，约于 1092 年完成。上层浑仪用于观测天体，中层浑象演示天球，下层由木人击钟、击鼓和出牌报时。

恒定水位使供水较稳定。水进入枢轮上的受水壶，水重达到阈值后压动天衡，释放止挡；枢轮转过一格，又被锁住。齿轮与天梯把这一节律传到各层。

本片依据《新仪象法要》所述原理进行教学化重构。原枢轮有 36 个受水壶；本模型展示 12 个，并简化复合擒纵、链传动路径与传动比。30 秒展示的是加速后的工作周期，不代表真实计时刻度。

所有运动机构均由本项目的约束物理引擎实时积分：重力水载荷、转动惯量、齿轮与链约束、止挡碰撞、凸轮接触及钟锤回落。镜头独立编排。声音由 Web Audio API 实时合成，开启后播放。
