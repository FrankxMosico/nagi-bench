# 造物纪 · 水运仪象台

一部 30 秒的实时 3D 科普短片。暖色木构、青铜机械、青绿色水流，采用剖开屋檐的教学模型，展示水如何依次推动计时和报时。

## 直接观看

双击 `dist/index.html` 即可。保留旁边的 `dist/assets/` 目录；无需网络、服务器或安装依赖。

页面自动播放。浏览器需要用户手势才能发声，点击右上角“开启声音”即可听到程序合成的配乐、水声、擒纵声和钟声。可暂停、拖动进度条、点击章节、重播；空格暂停，左右方向键前后跳 2 秒。“自由观察”可以拖动旋转、滚轮缩放和关闭水流，检验机械的因果关系。

## 开发与构建

```sh
bun run dev
bun run build
bun run check:physics
```

标准 Vite 项目。依赖版本为 `three@0.180.0`、`vite@8.2.0`；浏览器自检使用 `playwright-core@1.61.1`。不需要其他第三方运行时依赖。构建使用 native 配置加载器，兼容只读的 `node_modules`。Vite 输出 IIFE，HTML 引用本地经典脚本，因此 `file://` 不会遇到 ES module 的跨源限制。

## 镜头设计

| 时间 | 画面与因果 |
| --- | --- |
| 0–4 秒 | 钟楼全貌：上层浑仪、中层浑象、下层报时 |
| 4–10 秒 | 平水壶与水斗近景：稳流注水，水重产生转动力矩 |
| 10–16 秒 | 天衡擒纵：积水压下天衡，释放止挡，水轮进一格再锁止 |
| 16–22 秒 | 齿轮与天梯：把水轮的运动传到各层，传动比分配转速 |
| 22–27 秒 | 报时近景：拨销抬锤，脱离后回落击钟；木人出牌 |
| 27–30 秒 | 回到全貌，串起“水重—擒纵—传动—报时” |

## 机械运动如何产生

`src/physics.js` 是自实现的约束物理引擎，采用机械系统常用的约化坐标法。固定轴承预先消去受约束的自由度，转子保留转角和角速度，链条保留沿闭合导轨的位移。固定步长为 **1/240 秒**。

- 每个水斗的水质量由供水率积分得到。各斗的重力对轮轴产生 `m g r cos(θ)` 力矩。
- 水斗与天衡的承接接触产生载荷；配重提供回位力矩。天衡越过开锁角度才释放止挡。止挡与防倒转棘爪采用单向接触冲量及穿透修正，下一格的位置来自水轮的等距止挡几何。
- 齿轮和链条使用 `J M⁻¹ Jᵀ` 有效质量求解约束冲量，反作用力会回传给水轮。没有恒速电机，也没有按影片时间驱动机械的目标角。
- 凸轮/拨销通过弹性接触推起钟锤，接触力反作用于凸轮。脱离后钟锤在恢复力下回落；与钟的碰撞交换冲量并产生音效事件。
- 链节位置由积分得到的链条物理坐标和固定导轨约束重构。轮、轴、浑仪、浑象、天衡、报时转盘、拨销、钟锤与钟的姿态全部读取求解器状态。模型渲染层不控制机械的速度或目标位置。
- 水滴也采用重力积分；已接收的水用水斗中的集总质量与可见水量表示，没有进行全流体仿真。
- 播放、暂停、重播和跳转都作用于整个模拟时钟。跳转先从初始条件重算物理，并非给机械设置预制姿态。只有镜头和字幕使用时间编排。

### 教学化简

依据苏颂《新仪象法要》描述的工作原理进行重构，并非尺寸级考古复原。原枢轮有 **36 个受水壶**，片中展示 12 个，以便看清每一斗的工作。复合擒纵被约化为水重天衡、止挡与复位的等效机构；链条路径、传动比和报时拨销均简化。影片展示加速周期，水斗进一格不等于一个真实时辰。原装置需人工提水补给，本模型把上游补水视为边界条件，不模拟提水机构。页面“关于这次复原”也注明了主要简化。

## 声音与资产

所有几何体都在 `src/model.js` 中由基本几何、车削曲面和合批生成。牌匾与柔和接触阴影使用运行时 Canvas 生成，不读取图像、外部模型、字体或贴图文件。

`src/audio.js` 使用 Web Audio 振荡器、实时生成的噪声缓冲、滤波器、增益包络与反馈延迟合成声音。钟声来自物理碰撞事件，擒纵声来自释放/锁止事件；配乐为五声音阶的轻声泛音与持续低音。总线限幅压缩、平滑淡入淡出与保守增益用于避免爆音。无音频文件。

- `bun run build`：实际生成 `dist/`。
- `bun run check:physics`：30 秒连续积分、传动约束误差、真实击钟事件、干启动不动、停水后停止、重复计算一致。
- `scripts/preview-exact.mjs`：通过 Chromium 打开实际 `file:///workspace/dist/index.html`；可按精确物理时间截图，并检查暂停、重播、声音、停水、说明弹窗和手机布局。
